# SauceDemo QA Testing Project

A software testing portfolio project for the SauceDemo web application.

This repository contains manual testing documentation, Jira bug reports, and automated testing scripts using Selenium WebDriver and Pytest.

## Project Contents

| Folder | Description |
|---|---|
| [Manual Testing](./manual-testing/) | Manual test documentation and testing process |
| [Automation Testing](./automation-testing/) | Selenium and Pytest automated test scripts |
| [Bug Reports](./bug-reports/) | Bug report screenshots and supporting evidence |
| [Jira Issues](./jira-issues/) | Jira issue and test case documentation |

## Testing Activities

- Manual testing
- Functional testing
- Negative testing
- UI testing
- Bug reporting
- Retesting
- Regression testing
- Selenium automation
- Pytest test execution
- Test report generation

## Tools

- Jira
- Python
- Selenium WebDriver
- Pytest
- Git
- GitHub

## Testing Workflow

```text
Manual Testing
      ↓

Retesting

Automation Testing
      ↓
Regression Testing
      ↓
Test Documentation
```
