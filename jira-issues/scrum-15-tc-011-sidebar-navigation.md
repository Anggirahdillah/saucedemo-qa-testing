## Deskripsi

Test Case ID: TC-011
Test Scenario:
Verify Sidebar Navigation Functionality
Objective:
Memastikan menu sidebar dapat dibuka dan setiap pilihan navigasi berfungsi sesuai tujuan.
Precondition:
User sudah berhasil login dan berada di halaman Products.
Test Steps:

- Login menggunakan username: standard_user

- Masukkan password: secret_sauce

- Klik tombol Login.

- Klik ikon menu sidebar di pojok kiri atas.

- Periksa pilihan menu yang tersedia.

- Klik menu All Items.

- Amati halaman yang ditampilkan.

- Buka kembali menu sidebar.

- Klik menu About.

- Amati halaman yang ditampilkan.

Expected Result:
Sidebar berhasil terbuka dan menampilkan menu All Items, About, Logout, serta Reset App State.

- Menu All Items mengarahkan user kembali ke halaman Products.

- Menu About mengarahkan user ke halaman About.

- Navigasi berjalan tanpa error.

Actual Result:
Sidebar berhasil terbuka dan menampilkan menu All Items, About, Logout, dan Reset App State.
Status:
PASS
