Test Case ID: TC-012
Test Scenario:
Verify Logout Functionality
Objective:
Memastikan user dapat keluar dari aplikasi dengan menggunakan menu Logout.
Precondition:
User sudah berhasil login dan berada di halaman Products.
Test Steps:

- Login menggunakan username: standard_user

- Masukkan password: secret_sauce

- Klik tombol Login.

- Klik ikon menu sidebar di pojok kiri atas.

- Klik menu Logout.

- Amati halaman yang ditampilkan.

Expected Result:
User berhasil logout dan diarahkan kembali ke halaman login. Form username, password, dan tombol Login tampil kembali.
Actual Result:
User berhasil logout dan diarahkan kembali ke halaman login. Form username, password, dan tombol Login tampil kembali.
