## Deskripsi

Test Case ID: TC-020
Test Scenario:
Verify Remove Product Functionality
Objective:
Memastikan user dapat menghapus produk yang sudah ditambahkan ke cart.
Precondition:
User sudah berhasil login dan berada di halaman Products.
Test Steps:

- Login menggunakan username: standard_user

- Masukkan password: secret_sauce

- Klik tombol Login.

- Pilih produk Sauce Labs Backpack.

- Klik tombol Add to Cart.

- Buka halaman Cart.

- Pastikan produk Sauce Labs Backpack tampil.

- Klik tombol Remove pada produk tersebut.

- Amati isi cart.

Expected Result:
Produk berhasil dihapus dari cart. Produk tidak lagi tampil pada daftar cart dan jumlah item pada cart menjadi kosong.
Actual Result:
Produk berhasil dihapus dari cart. Produk tidak lagi tampil pada daftar cart dan jumlah item pada cart menjadi kosong.
Status:
PASS
